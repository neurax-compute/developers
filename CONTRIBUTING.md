# Contributing

Thank you for your interest in NEURAX Compute.

- **Examples and client library**: pull requests are welcome (new languages, fixes, examples for
  specific industries). Every contribution is released under the MIT license of this repository.
- **New API features or new computations**: first open an issue with the "Feature request" template
  describing your use case. The service is developed by the NEURAX team: proposals are evaluated
  and, if accepted, implemented by us.
- **Bugs**: include the request (without your API key), the response with its error code and,
  if there is one, the job id (`job_…`).

The code of the engine, the nodes and the coordinator is not public and does not accept external contributions.
