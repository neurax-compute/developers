# Security

If you find a vulnerability in the API, the portals or the client library, **do not open a public issue**.
Write to **info@swissgroupnetwork.ch** with the subject "NEURAX security", describing the problem and how
to reproduce it. We reply within 3 business days.

Do not run tests that degrade the service, access other customers' data or use social engineering.
Never publish API keys (`nxk_…`) in issues, discussions or code: if it happens, revoke the key
immediately in the customer portal.
